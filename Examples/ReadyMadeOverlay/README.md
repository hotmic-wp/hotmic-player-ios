# ReadyMadeOverlay

Open `ReadyMadeOverlay.xcodeproj`, select the `ReadyMadeOverlay` scheme and run on an iOS 17+ simulator. It builds the repository sources with HotMicPlayer + HotMicPlayerUI, fake social data and public sample video URLs. No credentials or backend are required.

Copy the app file into your app target and replace the media and callbacks with your service. Keep one player for the screen lifetime; use `isFeedVisible` for temporary hiding and terminal `teardown()` only when its owner is released. For app integration, use `.package(url: "https://github.com/hotmic-wp/hotmic-player-ios", exact: "1.0.0")`. The optional Connect adapter currently requires player `from: "1.1.0-alpha.1"` and cannot resolve this exact pin; this standalone starter needs no adapter or HotMic account. Each starter is one screen and under 200 lines of host code. The two paths use the same feed, layout, gestures and ad state. See the [Partner integration guide](../../Sources/HotMicPlayer/HotMicPlayer.docc/PartnerIntegrationGuide.md).
